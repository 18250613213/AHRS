# AHRS V0.1 implementation plan

Goal — Complete the user's approved reliability iteration and synchronize V0.1 to their GitHub repository.

Architecture — Keep the Qt application and parsers. Add a bounded-memory CSV recording session with asynchronous streaming Excel export. Track receive health independently from presentation. Keep a stable reader reference for file transfers and distinguish written bytes from device acknowledgement.

Spec — User-approved findings in this conversation, including close-time data loss, silent disk errors, stale telemetry, disconnect recovery, false transfer success, display precision and presentation lag.

Decisions — V0.1 names the optimized deliverable. A two-second valid-data timeout resets frequency. T02 uses direct attitude display by default. Unknown state codes remain numeric. T02 burning is unavailable until its programming protocol is supplied. Existing EB90 mode remains supported. Recordings stay local. GitHub destination must be identified before uploading.

## Tasks

- [ ] Add recording.py and test_recording.py. Write records incrementally to uniquely named CSV files, preserve files on export failure, stream Excel on a worker, and split sheets before Excel's row limit. Tests cover numeric/text fields, write errors, retry and splitting.
- [ ] Update main.py and add test_reliability.py. Exercise receive failure, two-second silence, persistent recording, close handling, raw disk failures and cancelled/failed transfers before fixing. Restore disconnected controls, serialize shutdown with receive work, and keep UI operations on the main thread.
- [ ] Complete display and V0.1 packaging. Connect raw-text/hex preview, use protocol precision, make attitude smoothing optional, add version and reproducible dependencies. Run the complete suite and live COM31 verification, then build and verify EXE.
- [ ] Run an independent final code review and resolve important findings. Prepare README, change log and Git ignore rules. Establish the requested remote, preserve its existing history, commit and publish V0.1 with remote verification.

## Review focus

Concurrent recording stop and callback, disk-full error paths, export failures and shutdown, reader identity during transfers, and disconnect or silence after healthy data.

## Progress

Initial repository discovery found no local Git metadata and no repositories returned by the GitHub connector. A destination question is pending while implementation continues.
